PicGo下载

PicGo下载链接

找到对应想要的版本下载就行。

配置图床

  1. 在GitHub上创建一个仓库用于存放图片
  2. 去 GitHub → Settings → Developer settings → Personal access tokens → 生成一个 token，勾选 repo 权限（选带classic那个）
  3. 然后配置PicGo里面的GitHub图床

5.配置Typora

补充：PicGo如果没连上（验证有点久就需要设置一下代理魔法了）
